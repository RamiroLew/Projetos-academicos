# Projetos Acadêmicos

Repositório com exercícios e trabalhos desenvolvidos durante a disciplina de Lógica de Programação, no curso de Análise e Desenvolvimento de Sistemas.

## 📚 Sobre

Os programas aqui exploram conceitos fundamentais de lógica e estruturação de código em **C**, como:

- Estruturas de controle de fluxo (if/else, switch)
- Laços de repetição (while, for, do-while)
- Funções e modularização
- Structs

## 🛠️ Tecnologias

- Linguagem C
- VS Code

## 📈 Status

Repositório em atualização conforme novos trabalhos da disciplina forem concluídos.
